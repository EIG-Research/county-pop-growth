# EIG Logo File Inventory

The approved EIG logo files and the Agglomerations sub-brand logo files. The usage rules, including the 2022 guide's incorrect-usage list, are in `Infrastructure/style/docs/eig-brand-guidelines.md` §1.

---

## EIG logo versions

| Version (2022 guide) | Files | Colors (from the SVG masters) |
|---|---|---|
| Full Color | `EIG_fullcolor.*` | Icon in the palette's `eig_tan_500`; wordmark in near-black |
| One-Color Black | `EIG_blackandwhite.*` | Near-black throughout |
| One-Color Reversed | `EIG_reverse.*` | White throughout |

---

## Files

### SVG (vector; preferred for the web and anything that scales)

| File | Version |
|---|---|
| `eig/svg/EIG_fullcolor.svg` | Full color |
| `eig/svg/EIG_blackandwhite.svg` | One-color black |
| `eig/svg/EIG_reverse.svg` | One-color reversed |

### PNG (raster with transparency; slides, documents, email, social media)

| File | Version | Size |
|---|---|---|
| `eig/png/EIG_fullcolor.png` | Full color | 1× |
| `eig/png/EIG_fullcolor@2x.png` | Full color | 2× (high-DPI screens) |
| `eig/png/EIG_blackandwhite.png` | One-color black | 1× |
| `eig/png/EIG_blackandwhite@2x.png` | One-color black | 2× |
| `eig/png/EIG_reverse.png` | One-color reversed | 1× |
| `eig/png/EIG_reverse@2x.png` | One-color reversed | 2× |

### EPS (vector; print and layout files)

| File | Version |
|---|---|
| `eig/eps/EIG_fullcolor.eps` | Full color |
| `eig/eps/EIG_blackandwhite.eps` | One-color black |
| `eig/eps/EIG_reverse.eps` | One-color reversed |

### JPG (raster, no transparency; press-ready files that need a CMYK profile)

| File | Version | Notes |
|---|---|---|
| `eig/jpg/EIG_fullcolor_CMYK-100.jpg` | Full color | CMYK |
| `eig/jpg/EIG_fullcolor_CMYK@2x-100.jpg` | Full color | CMYK, 2× |
| `eig/jpg/EIG_blackandwhite.jpg` | One-color black | |
| `eig/jpg/EIG_blackandwhite@2x.jpg` | One-color black | 2× |

A JPG has no transparency, so place it on white.

### AI (Illustrator masters)

| File | Contents |
|---|---|
| `eig/ai/EIG_fullcolor.ai` | Full color master |
| `eig/ai/EIG_blackandwhite.ai` | One-color black master |
| `eig/ai/EIG_reverse.ai` | One-color reversed master |
| `eig/ai/EIG_all_variations.ai` | All versions in one file |

Only the brand designer edits these; everyone else uses the exported files.
