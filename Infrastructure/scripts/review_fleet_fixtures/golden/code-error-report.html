State join is many-to-many and duplicates workers

Claim
The join duplicates worker rows because states.csv has two rows for S03.
Found
The join declares no relationship, and the row count rises after it.
Quoted
workers_with_region <- inner_join(
  workers_raw,
  states_raw,
  by = "state_code"
)
Verified by

Command
Rscript review-reports/_scratch/check_join.R
Refutation tried
Looked for a distinct() or a row-count check after the join; there is none.
Why it matters
Duplicated workers inflate every weighted mean and the regression N.
Fix
Add relationship = "many-to-one" and unmatched = "error" to the join, and deduplicate states.csv.
