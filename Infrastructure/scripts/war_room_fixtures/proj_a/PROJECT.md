# Fixture Project A

Synthetic project used only by the war-room test fixtures. Nothing in it is a real
analysis, and no number in it is a real number.

## Research Question

None. This shell exists so that project-root resolution has a directory containing a
PROJECT.md to walk up to, and so that the war-room scripts have a project id to record.

## Layout

The code directory holds one synthetic script per supported language. The a and b
directories hold two same-named scripts at different paths, so that slug generation can
be shown to distinguish them.
