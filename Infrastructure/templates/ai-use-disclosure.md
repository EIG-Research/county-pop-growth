# AI-Use Ledger and Disclosure Template

The shell for the project's AI-use ledger at `records/ai-use-log.md`, and for the disclosure
statement built from it (`Infrastructure/rules/ai-use-disclosure-rules.md`). Create the ledger
from everything below the rule on first use, then append one row per AI use and session.

- Category is one of: code, data or text analysis, editing feedback, figure or table code,
  images, other.
- Outputs names repository paths, or the work product and section.
- Reviewed by is the person who checked the output; leave it `pending` until someone has.
- At handoff, write one disclosure line per category used, name the tool, and record it in the
  cover sheet's `AI Use Disclosure` field. The author confirms the statement.
