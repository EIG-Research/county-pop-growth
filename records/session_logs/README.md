# Session Logs Folder

Store all recorded session logs in this folder.

## Naming convention

`YYYY-MM-DD_description.md`

This is the convention defined by `Infrastructure/rules/session-logging.md`, which is
authoritative. Use an underscore after the date and a short kebab-case description, for
example `2026-01-15_data-cleaning.md`.

Use `Infrastructure/templates/session_log.md` as the base template.
